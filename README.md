# FIFA 19 Player Analysis & Overall Rating Prediction

Exploratory analysis of the full FIFA 19 player database (18,207 players, 89 attributes), followed by a Linear Regression model that predicts a player's `Overall` rating from their individual skill and physical attributes, interpreted with permutation importance.

## Dataset

The [FIFA 19 complete player dataset](https://www.kaggle.com/karangadiya/fifa19) (scraped from sofifa.com), 18,207 rows × 89 columns covering every registered player: identity fields (name, age, nationality, club), market fields (value, wage, release clause), and 34 individual skill ratings (crossing, finishing, dribbling, reactions, etc.) plus goalkeeping attributes.

The raw CSV (~9 MB) isn't committed to this repo — it's a large, publicly available Kaggle file. Download it from the link above as `data.csv` in the repo root to reproduce the results below.

## Approach

**Cleaning.** Rows missing `Height` turned out to be missing nearly every physical/skill column too (verified by checking that the missing `Height` and `Weight` row indices matched exactly), so those rows were dropped rather than imputed.

**Feature engineering.**
- Dropped the 26 position-specific overall ratings (`LS`, `ST`, `RS`, ... `RB`) before modeling — these are FIFA's own derived scores built from the base attributes, so leaving them in would leak information about `Overall`.
- `Real Face` and `Preferred Foot` → binary indicators.
- `Position` → collapsed into 6 simplified groups (GK / DF / DM / MF / AM / ST) instead of 27 granular positions, to avoid a huge sparse one-hot block from a low-signal field.
- `Nationality` → binary "major nation" flag (countries with 250+ players in the dataset), since one-hot encoding 164 countries individually would mostly add noise.
- `Work Rate` (e.g. `"Medium/ Medium"`) → split into separate attack/defense work-rate columns.
- Remaining categoricals one-hot encoded, giving 54 final features.

**Modeling.** 80/20 train/test split, Linear Regression, evaluated with R² and RMSE. Feature importance measured with permutation importance (shuffle one column at a time on the held-out test set, measure the drop in R²) rather than raw regression coefficients, since the one-hot categorical blocks make coefficient magnitudes hard to compare directly.

## Results

| Metric | Value |
|---|---|
| R² (test set) | **0.929** |
| RMSE (test set) | **1.82** (on a 0–100 rating scale) |

A linear model explains ~93% of the variance in a player's `Overall` rating from their attributes alone, with predictions typically within about 2 rating points.

**Top features by permutation importance:**

| Rank | Feature | Importance (mean R² drop) |
|---|---|---|
| 1 | Potential | 0.371 |
| 2 | Age | 0.203 |
| 3 | Reactions | 0.078 |
| 4 | Ball Control | 0.065 |
| 5 | GK Reflexes | 0.049 |
| 6 | GK Diving | 0.030 |
| 7 | Heading Accuracy | 0.026 |
| 8 | GK Handling | 0.023 |
| 9 | Short Passing | 0.021 |
| 10 | Skill Moves | 0.015 |

`Potential` and `Age` dominate by a wide margin — FIFA's own rating system leans heavily on a player's ceiling and career stage before it gets to any single on-pitch skill. `Reactions` and `Ball Control` are the strongest individual skill ratings, and the goalkeeping attributes (`GK Reflexes`, `GK Diving`, `GK Handling`) show up high on the list simply because they're near-zero for outfield players and highly predictive for the ~2,000 goalkeepers in the dataset.

**Caveat:** `Overall` is itself a composite FIFA computes from a player's sub-skill ratings, so this is closer to reverse-engineering FIFA's own weighting formula than predicting an independent outcome — worth keeping in mind when reading the R² as "the model understands football."

## Exploratory findings

- 164 nationalities represented; England (1,662), Germany (1,198), and Spain (1,072) have the most players in the database.
- 651 clubs, with FC Barcelona, Manchester United, Manchester City, Chelsea, and Real Madrid all fielding the maximum 33-player squads.
- Highest `Potential`: Kylian Mbappé (95). Highest `Overall`: Lionel Messi (94).
- Most valuable player: Neymar Jr (€118.5M). Highest wage: Lionel Messi (€565K/week).
- `Potential` falls steadily with age, and `Sprint Speed` declines noticeably as players get older.
- Goalkeeping attributes are almost uncorrelated with outfield skills but tightly correlated with each other, as expected.
